# Client vault

- `get_vault_choices`: What a paper or a certificate can name
- `list_vault_documents`: The business’s papers
- `add_vault_document`: Add a paper
- `start_vault_document_upload`: Get an address to send a paper’s file to
- `get_vault_document`: A paper
- `change_vault_document`: Change a paper
- `delete_vault_document`: Delete a paper
- `get_vault_document_download`: An address that downloads a paper’s file
- `remove_vault_document_file`: Take a paper’s file away
- `list_dscs`: The business’s digital signature certificates
- `add_dsc`: Add a digital signature certificate
- `get_dsc`: A digital signature certificate
- `change_dsc`: Change a digital signature certificate
- `delete_dsc`: Delete a digital signature certificate
