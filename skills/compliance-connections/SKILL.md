# Connections

- `list_books_uploads`: The files the books were sent as
- `create_books_upload`: Send the books as a file
- `start_books_file`: Where to send a file of books documents
- `list_books_upload_formats`: The kinds of file the books can be sent as
- `get_books_upload`: A file the books were sent as
- `map_books_upload`: Match the file’s columns to what they hold
- `list_connections`: The organization's connections
- `create_connection`: Connect the books or the payroll, or connect them again
- `list_connection_providers`: The books and payroll sources that can be connected
- `get_connection`: A connection
- `disconnect_connection`: Disconnect the books
- `choose_connection_account`: Choose which account the connection reads
- `sync_connection`: Sync the books now
- `list_connection_syncs`: A connection's syncs
- `list_source_transactions`: The documents read from the books
