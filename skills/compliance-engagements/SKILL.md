# Engagements

- `take_back_access_grant`: A business’s owner took a firm’s access back
- `list_engagements`: The firms the organization hired, and what each does
- `invite_firm`: Invite a firm on this service to do some obligations
- `accept_firm_invitation`: Accept a firm’s invitation to do some obligations
- `decline_firm_invitation`: Decline a firm’s invitation
- `end_engagement`: End an engagement with a firm
- `answer_notification`: A member answered an invitation on its message
- `list_period_requests`: What the firm doing a period asked for it
- `list_requests`: What firms asked the organization for
- `answer_request`: Answer a firm’s request
- `answer_request_item`: Answer an item of a firm’s request
- `add_request_item_file`: Send a file for an item of a firm’s request
