# Firm clients obligation periods proofs

- `list_client_proofs`: The files that prove a client’s filing, oldest first
- `add_client_proof`: Add a sent file as proof of a client’s filing
- `start_client_proof_upload`: Get an address to send a proof of a client’s filing to
- `remove_client_proof`: Remove a proof of a client’s filing added by mistake
- `get_client_proof_download`: An address that downloads a proof of a client’s filing
