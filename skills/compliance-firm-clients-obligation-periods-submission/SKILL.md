# Firm clients obligation periods submission

- `get_client_return_submission`: Where filing a client’s return at the government stands
- `start_client_return_submission`: Send a prepared return to the government
- `check_client_return_filed_at_government`: Check that a client's return was filed at the government's portal
- `request_client_return_filing_code`: Send the signatory the code that files a client’s return
- `continue_client_return_submission`: Look again at the government's work on a client’s return sent
- `file_client_return_submission`: File a client’s return at the government with the signatory's code
- `read_client_return_ledgers`: Read the cash and credit held at the government for a client’s return
- `reset_client_return_submission`: Discard a client's return saved at the government
