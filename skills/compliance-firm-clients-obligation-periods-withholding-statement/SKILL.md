# Firm clients obligation periods withholding statement

- `get_client_withholding_statement`: A client’s return of tax withheld, prepared from their books
- `answer_client_withholding_questions`: Answer what a client’s books do not say
- `download_client_withholding_correction_file`: Download the correction of a client’s filed statement
- `add_client_withholding_deposit`: Add a deposit of a client’s tax withheld
- `read_client_withholding_deposits`: Read a client's deposits from the government's records
- `remove_client_withholding_deposit`: Remove a deposit entered by mistake on a client’s return
- `read_client_withholding_deposit_detail`: Read one of a client's deposits whole from the government's records
- `download_client_withholding_file`: Download a client’s statement as its upload file
- `read_client_withholding_filed_return`: Read the government's file of a client's return as filed
- `set_client_withholding_filer`: Give who files a client's returns
- `file_client_withholding_return`: File a client’s return of tax withheld
- `read_client_withholding_certificates`: Read a client's payees' certificates from the government
- `give_client_withholding_filing_code`: Give the code sent to a client's mobile
- `send_client_withholding_filing_code`: Send a client's mobile a new code
- `file_client_withholding_correction`: File a correction of a client's return as filed
- `give_client_withholding_filing_deposit_file`: Give a client's deposits' file instead of the code
- `get_client_withholding_notice_check`: Whether a client's return is checked for notices, and the latest check
- `check_client_withholding_notices`: Check a client's return for notices before filing
- `get_client_withholding_payee_check`: How many of a client's payees' tax numbers a check would check, and the latest check
- `check_client_withholding_payees`: Check a client's payees' tax numbers at the government
- `attach_client_withholding_prepared_return`: Keep a client’s statement as the return as prepared
- `read_client_withholding_provider_jobs`: Read a client's return's jobs at the provider
- `get_client_withholding_file_validation`: Whether a client’s upload file is validated here, and the latest validation
- `validate_client_withholding_file`: Validate a client’s upload file with the government’s utility
