# Firm clients vault

- `get_client_vault_choices`: What a client’s paper or certificate can name
- `list_client_vault_documents`: A client’s papers
- `add_client_vault_document`: Add a paper for a client
- `start_client_vault_document_upload`: Get an address to send a client’s paper’s file to
- `get_client_vault_document`: A client’s paper
- `change_client_vault_document`: Change a client’s paper
- `delete_client_vault_document`: Delete a client’s paper
- `get_client_vault_document_download`: An address that downloads a client’s paper’s file
- `remove_client_vault_document_file`: Take a client’s paper’s file away
- `list_client_dscs`: A client’s digital signature certificates
- `add_client_dsc`: Add a digital signature certificate for a client
- `get_client_dsc`: A client’s digital signature certificate
- `change_client_dsc`: Change a client’s digital signature certificate
- `delete_client_dsc`: Delete a client’s digital signature certificate
