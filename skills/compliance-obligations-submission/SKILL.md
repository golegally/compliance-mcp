# Obligations submission

- `get_return_submission`: Where filing a return at the government stands
- `start_return_submission`: Send a prepared return to the government
- `check_return_filed_at_government`: Check that a return was filed at the government's portal
- `request_return_filing_code`: Send the signatory the code that files a return
- `continue_return_submission`: Look again at the government's work on a return sent
- `file_return_submission`: File a return at the government with the signatory's code
- `read_return_ledgers`: Read the cash and credit held at the government for a return
- `reset_return_submission`: Discard the return saved at the government
- `settle_return_submission`: Pay a return's tax from the credit and cash held at the government
