# Proofs

- `list_proofs`: The files that prove a filing, oldest first
- `add_proof`: Add a sent file to a filing: its prepared return, or a proof
- `start_proof_upload`: Get an address to send a proof file to
- `remove_proof`: Remove a proof added by mistake
- `get_proof_download`: An address that downloads a proof
- `list_proofs_of_periods`: The files that prove the filings of several periods
