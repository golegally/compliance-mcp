# Rule library

- `list_rule_library_activity`: The activity log: every operator action, newest first
- `apply_rule_library_change`: Publish drafts and retire versions, as one change
- `list_rule_records`: The library’s records, by country and kind
- `create_rule_record`: Add a record (a kind and key in a country); its content comes in drafts
- `get_rule_record`: A record with every version, drafts and retired ones included
- `create_rule_draft`: Draft a new version of a record
- `set_rule_record_words`: Change the words people read for a record
- `get_rule_library_settings`: The library’s settings
- `update_rule_library_settings`: Change the library’s settings (review on publish)
- `edit_rule_draft`: Edit a draft; a published version is never edited
