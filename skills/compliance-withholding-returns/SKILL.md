# Withholding returns

- `get_withholding_statement`: A return of tax withheld, prepared from the books
- `answer_withholding_questions`: Answer what the books do not say
- `download_withholding_correction_file`: Download the correction of the filed statement
- `add_withholding_deposit`: Add a deposit of the tax withheld
- `read_withholding_deposits`: Read the deposits from the government's records
- `remove_withholding_deposit`: Remove a deposit entered by mistake
- `read_withholding_deposit_detail`: Read one deposit whole from the government's records
- `download_withholding_file`: Download the statement as its upload file
- `read_withholding_filed_return`: Read the government's file of the return as filed
- `set_withholding_filer`: Give who files the registration's returns
- `file_withholding_return`: File the return of tax withheld
- `read_withholding_certificates`: Read the payees' certificates from the government
- `give_withholding_filing_code`: Give the code sent to the payer's mobile
- `send_withholding_filing_code`: Send the payer's mobile a new code
- `file_withholding_correction`: File a correction of the return as filed
- `give_withholding_filing_deposit_file`: Give the deposits' file instead of the code
- `get_withholding_notice_check`: Whether the return is checked for notices, and the latest check
- `check_withholding_notices`: Check the return for notices before filing
- `get_withholding_payee_check`: How many payees' tax numbers a check would check, and the latest check
- `check_withholding_payees`: Check the payees' tax numbers at the government
- `attach_withholding_prepared_return`: Keep the statement as the return as prepared
- `read_withholding_provider_jobs`: Read the return's jobs at the provider
- `get_withholding_file_validation`: Whether the upload file is validated here, and the latest validation
- `validate_withholding_file`: Validate the upload file with the government’s utility
